# LiteModbus — Modbus TCP 主从站调试工具 · 设计系统

## 产品上下文

- **产品**: LiteModbus，macOS 原生 Modbus TCP 调试工具，Master（主站）与 Slave（从站仿真）集成在一个 app 内，面向嵌入式 / 自动化工程师的日常联调。
- **核心 JTBD**: 主站连上设备后批量轮询点位、给点位起变量名、按位（40001.1）读写；把关键点位提出来做成看板盯数；把一组值存成配方一键下写；从站侧仿真寄存器并像 Modbus Slave 软件一样以多格式（Word/Hex/无符号/有符号/Float）查看与双击修改。
- **目标用户**: 熟悉 Modbus 地址约定（0x/1x/3x/4x、40001 式编号）的工业开发者，界面文案中文优先，地址/功能码等协议术语保持通用。
- **外观**: 同时支持系统浅色与深色外观（跟随系统切换），与仓库内 DevCalc 同一套原生 mac 语义色板语言。

## 信息架构

- 单窗口，左侧原生边栏（NavigationSplitView），分组：
  - **主站**: 看板（默认页）、点位表、配方、报文日志
  - **从站**: 寄存器仿真
- 顶部工具栏承载连接与轮询控制（主机/端口/Unit ID/连接、轮询间隔、开始停止、周期耗时）。
- 边栏底部常驻连接状态点（绿=已连接，灰=未连接，红=错误）。

## 表格（工具的核心控件）

- macOS 原生内嵌表格质感：表头小号 11px semibold 次级文字色、大写不强制的中文列头、行高 28px、列间发丝分隔、整行选中用 accent 8% 填充 + 左缘 3px accent 竖条。
- 所有数值列等宽 SF Mono 右对齐；名称列 SF Pro 左对齐；双击可编辑的单元格出现 accent 描边内嵌输入框。
- 位编辑（40001.1）：寄存器行可展开 16 个位格，置 1 = accent 填充白字，置 0 = insetBackground 灰字，bit0 在最右（LSB 右对齐约定）。

## 字体

- 界面标签 / 表头 / 按钮: SF Pro Text（栈: -apple-system, "SF Pro Text", "PingFang SC"）
- 所有地址、数值、HEX、报文: 等宽 SF Mono（栈: "SF Mono", ui-monospace, Menlo）
- 字号: 看板大数值 34px semibold 等宽；表格正文 13px；表头 11px；连接栏输入 13px 等宽；报文 HEX 11px 等宽；卡片标签 12px。

## 动效

- 数值刷新: 变更时 200ms flash 背景淡出；轮询周期指示每周期一次轻微脉冲。
- 侧栏切换 / 卡片载入: 150ms 淡入；外观切换由系统接管。

## 布局规格

- 窗口: 默认 1280 × 800pt，最小 1120 × 720。
- 垂直结构: 标题栏（含工具栏控件）→ 内容区 → 底部状态条（22px：连接状态、周期耗时、Tx/Rx/Err 计数、数据目录路径）。
- 点位表列序: 变量名称 / 地址 / 位 / 类型 / 字节序 / 读值 / 上次更新 / 看板开关 / 操作。
- 从站寄存器表列序（对照 Modbus Slave 软件）: 地址 / 变量名称 / Word / Hex / 无符号 / 有符号 / Float / 位格。

## 设计稿要求

- 每页设计稿**并排呈现浅色与深色两个 macOS 窗口**（各含红绿灯），放在中性背景上，两窗口结构/字号/布局完全一致，仅色板不同。
- 界面文案中文优先；地址、功能码、类型名（Word/Float/ABCD…）保持协议通用写法。

## 项目要求

- 禁止: 渐变彩虹配色、彩色霓虹、非系统字体（不用 Inter/Roboto）、网页风大圆角卡片阴影堆叠。
- 数据一律 JSON 存储（点位、配方、从站快照），界面不得出现"云端/账号"类元素，本地工具，简洁无广告。

# DevCalc — macOS 程序员计算器 · 设计系统

## 产品上下文

- **产品**: DevCalc，一款 macOS 原生计算器 app，目标是替代 macOS 自带计算器（其程序员模式难用：不能同时查看各进制、没有位翻转面板、位运算入口隐蔽）。
- **主模式**: 程序员计算器（核心，设计的绝对重点）。**次模式**: 基本计算器。
- **目标用户**: 开发者 / 嵌入式工程师，日常做进制转换、位运算、协议字段拼装。
- **核心 JTBD**: 快速在 HEX/DEC/OCT/BIN 间换算；执行位运算并立即看到各进制结果；按位翻转某个 bit 验证寄存器值。
- **外观**: 必须同时支持系统浅色与深色外观（跟随系统切换），同一套语义色板在两种外观下都保持原生质感。

## 关键功能布局（程序员模式）

1. **模式行**: 模式切换（基本 / 程序员）+ 字长切换（8 / 16 / 32 / 64 位）+ 有符号 / 无符号切换。
2. **进制显示区**: 四行右对齐，HEX / DEC / OCT / BIN 同屏显示；点击任意行切换为"当前输入进制"；当前进制行左侧 3px 圆角强调色竖条 + 标签变强调色；HEX 按字节分组（`73 BD 5A 2C`），DEC 按千位分组；上方一行灰色小字的上次运算表达式。
3. **位翻转面板**: 全部字长位数的可点击 bit 格子，16 位一行（8 位字长单行 8 格），MSB 在左上，每 8 位（字节）有视觉分隔；置 1 用强调色填充。
4. **键盘区**: 十六进制键 A–F；位运算 AND / OR / XOR / NOT / NAND / NOR；移位 << >> 与循环移位 RoL / RoR；Mod、±、CE / C / ⌫、÷ × − + =、数字 0–9（基本模式含小数点与 %）。
5. 物理键盘与按键一一对应（实现细节，设计稿不呈现）。

## 语义色板（唯一颜色来源，所有颜色都是"角色"而非具体值）

| 语义角色 | 浅色外观 | 深色外观 |
| --- | --- | --- |
| 窗口背景 windowBackground | `#F4F4F7` | `#1B1B1D` |
| 数字键 keyDigit | `#FBFBFD` | `#5E5E63` |
| 功能键 keyFunction（CE/C/⌫/±/Mod/移位/位运算） | `#E3E3E8` | `#3A3A3E` |
| 十六进制键 keyHex（A–F） | `#DCE9F2` | `#35566B` |
| 强调色 accent（运算符 ÷×−+、等号、当前进制行、置 1 的 bit、分段控件选中） | `#007AFF` | `#0A84FF` |
| 次级文字 labelGray（进制标签、表达式行、bit 0） | `#6E6E73` | `#8E8E93` |
| 发丝线 hairline | black 10% | white 8% |
| 主文字 primary | 系统标签色（近黑） | 系统标签色（近白） |
| 错误 error | 系统红 `#FF3B30` | 系统红 `#FF453A` |

- **按键文字色**: 强调色键（÷×−+=、等号）与十六进制键 → 白色（两种外观一致）；数字键与功能键 → 浅色外观用近黑 `#1C1C1E`，深色外观用白色。
- **bit 格子**: 置 1 = accent 填充白字 "1"；置 0 = 浅色外观 black 5% / 深色外观 white 6% 的低调格子，灰字 "0"。
- 禁止渐变彩虹、霓虹色；同一角色不得在两种外观下混用其它色值。

## 按键造型与材质

- 深浅两种外观均为纯色填充 + 1px 发丝描边（浅色外观描边负责轮廓感，深色外观负责层次）。
- 圆角矩形 radius 10px；键间距 6px；按下态：亮度 +8% 并缩放 0.97。
- 窗口圆角 10px，顶部标题栏与窗口背景同色，红绿灯随系统外观渲染。

## 字体

- 界面标签 / 模式控件: SF Pro Text（栈: -apple-system, "SF Pro Text", "PingFang SC"）
- 所有数值显示（HEX/DEC/OCT/BIN、bit 面板、表达式行）: 等宽 SF Mono（栈: "SF Mono", ui-monospace, Menlo）——进制对齐是硬需求
- 字号: DEC 40px 细体（主显示）；HEX 24px semibold；OCT 17px；BIN 15px；进制标签 11px；表达式行 12px 等宽；普通按键 18px；位运算等小按键 12px semibold；bit 格子 12px 等宽。

## 动效

- 按键按下: 60–100ms 缩放 0.97 + 透明度 0.8，释放回弹。
- 数值变化 / 进制切换: 150ms 淡入；外观切换由系统接管，不做自定义过渡。

## 布局规格

- 窗口: 约 640 × 760pt，最小 600 × 700。
- 垂直结构: 标题栏 → 控制/模式行 → 发丝分隔线 → 进制显示区 → 位翻转面板 → 键盘区（占余高）。
- 键盘栅格: 上三行 6 列（A–F / 位运算 / 移位 Mod ±），下五行 4 列（CE C ⌫ ÷ / 数字 × − + / 0 跨 2 列 + = 跨 2 列）。

## 项目要求

- 设计稿需**并排呈现浅色与深色两个 macOS 窗口**（各含红绿灯），放在中性背景上，两窗口结构/字号/布局完全一致，仅色板不同。
- 界面文案中文优先（模式名、开关标签），进制标签与按键符号保持通用（HEX/DEC/OCT/BIN、AND/OR…、数字）。
- 禁止: 渐变彩虹配色、彩色霓虹、非系统字体（不用 Inter/Roboto）。
